# Review round template

> The skeleton of one review round's summary comment. Copy it, fill every part, and delete
> the hints. The rules behind it are in [REVIEW.md](../../../REVIEW.md); where they differ, REVIEW.md wins.

<a id="template"></a>
## The comment
<!-- @section
depends_on = ["REVIEW#output", "REVIEW#rounds"]
-->

Parts appear in this order, and none is left out: write "None" where a part is empty.

````markdown
## Review · round <n> · <sha7>

<One paragraph: what this PR does, which kind of round this is (full, merge-only, lane value,
draft, wave landing, bot rebase), and what was read.>

### Earlier findings
- **B1:** resolved in <sha7> (`path:line`). / still open: <why>. / withdrawn: <why the rebuttal holds>.
- **N2:** …

### Analysis
**<Topic>.** <What was checked and what holds.>

### Docs re-verifications
- `DOC#anchor`: holds. <What its note says, and why that matches the diff.>
- `DOC#anchor`: doesn't hold. <What is wrong.> → B<n>

### Findings
**B<n> · blocking · <rule id> · `path:line`**
Problem: <what is wrong>.
Path: <the input or caller that reaches it>.
Fix: <the smallest change that resolves it>.

**N<n> · non-blocking · `path:line`**
Problem: …
Fix: …

### Governance, description, CI
- Governance: <what `repo governance` flagged, and whether the label and section are right>.
- Security: <anything touching secrets, permissions or untrusted input, or "None">.
- PR description: <answers the template; trailers `Completes:` / `Part-of:` correct>.
- CI at <sha7>: <green / which checks are red, and whose they are>.

<!-- review v1 verdict=<pass|fail|escalate|recuse> sha=<40-char head SHA> round=<n> reviewer-session=<session id> -->
<✅ No blocking issues at <sha7> (round <n>). Non-blocking: N1. / ❌ <k> blocking issue(s) at <sha7>: B1, B3 / ⚠️ Needs the maintainer: <what> / ↩️ Recused: this session authored the PR>

---
_Generated by [Claude Code](https://claude.ai/code)_
````

> [!CAUTION]
> One marker per round, never edited after posting. An edited comment doesn't count, so a
> correction is a new round with the next round number.
