# Code of conduct

<a id="pledge"></a>
## Our standard
<!-- @section
-->

This project adopts the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
Everyone taking part in its issues, pull requests and discussions follows it.

<a id="enforcement"></a>
## Enforcement
<!-- @section
-->

Report unacceptable behaviour to the maintainer through the contact on the repository
owner's GitHub profile. The maintainer reviews every report and decides the response.
