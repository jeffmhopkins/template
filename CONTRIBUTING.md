# Contributing

> Outside pull requests are closed until the first release; issues are welcome. Agents make
> every change, and the review gate lands it.

<a id="closed"></a>
## Outside contributions
<!-- @section
-->

This repo does not accept outside pull requests until its first release. Issues are
welcome: bug reports, with steps to reproduce, and feature requests. Security reports go
through [SECURITY.md](SECURITY.md), not issues.

<a id="how-work-lands"></a>
## How work lands
<!-- @section
-->

Every change is made by an agent session under [CLAUDE.md](CLAUDE.md), reviewed under
[REVIEW.md](REVIEW.md), and merged by GitHub auto-merge once every required check is green.
The rules are in [docs/RULES.md](docs/RULES.md). Everyone taking part follows the
[code of conduct](CODE_OF_CONDUCT.md).
